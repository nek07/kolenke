# JobBot: автоотклики и рассылка резюме

Запуск: двойной клик по `start.command`, откроется http://127.0.0.1:8765
(первый запуск сам установит зависимости).

1. **Настройки**: имя, телефон, должность, файл резюме (PDF), Gmail и пароль приложения
   (myaccount.google.com → Безопасность → Пароли приложений).
2. **HeadHunter**: «Войти в hh» → войдите в окне браузера и закройте его. Затем задайте запрос,
   нажмите «Найти вакансии», отметьте нужные, «В очередь», «Откликнуться на очередь».
   Вакансии с тестом от работодателя пропускаются: на них откликайтесь вручную.
3. **Письма компаниям**: CSV/Excel с колонками «компания; email; должность» → «Письмо» (предпросмотр)
   → отметить → «В очередь» → «Отправить очередь».
   Главная цифра на «Сегодня» — **приглашения за неделю** и доля откликов, которые заканчиваются приглашением.
   Цель по откликам недельная; «не больше откликов в день» — только защита аккаунта от капчи.
   **Автопилот** работает в двух режимах: «С проверкой» (находит свежие вакансии, присылает уведомление,
   вы пролистываете карточки «Откликнуться / Пропустить») и «Полностью сам».
   **Умные фильтры** в «Параметрах поиска»: зарплата не ниже, пропуск вакансий без зарплаты, опыт,
   компании-исключения, без повторных откликов туда, где был отказ, минимальное совпадение навыков (метка hh).
   Клик по строке вакансии открывает её историю: когда найдена, почему прошла фильтры, резюме, письмо,
   ответы в анкете, переписка и реакция работодателя.
4. **Другие сайты**: быстрый поиск на Habr Career / SuperJob / LinkedIn / Enbek и трекер откликов.

Все данные (база, пароль почты, сессия браузера) хранятся только локально в папке `data/`.

## Тесты

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests -q
```

Тесты работают на временной базе (`JOBBOT_DATA`), без hh, Gmail и уведомлений: логика фильтров, базы ответов,
воронки и напоминаний, API и защита от чужих сайтов, а также настоящий браузер без окна проверяет все вкладки.
Действия на самом hh (отклик, письмо, чат) тестами не покрыты — они зависят от вёрстки hh.
